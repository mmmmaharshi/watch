# Glossary

Single context for the `watch` port effort. Terms only — no implementation.

## Port

Re-implementing the `watch` app on the CAFE stack (Cloudflare + Alchemy + Foldkit + Effect + XState) with behavior unchanged, judged by `docs/agents/acceptance.md`. A port adds no features and redesigns no flows.

## Parity

The state of behaving exactly like the current app: same lookups, same results, same links, same notes. The acceptance criteria define it; the e2e suite checks it.
